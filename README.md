# Job Application Tracker (Blazor Server)
A personal job application tracking web app built with:
- Blazor Server
- Entity Framework Core
- SQLite
- Bootstrap

## Features
- Track job applications
- Status & next-action workflow
- Edit / delete applications
- Local-first (your data stays on your machine)

## Requirements
- .NET 8 or newer
- SQLite (bundled automatically)


## TO Start 
- Clone Repo -> dotnet build -> dotnet run
